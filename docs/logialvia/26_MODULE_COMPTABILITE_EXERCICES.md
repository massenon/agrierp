## 1. Objectif

Comptabilité de « niveau professionnel » conforme SYSCOHADA révisé : chaque opération commerciale génère ses écritures équilibrées ; Journal, Grand Livre, Balance, Bilan, Compte de résultat, TAFIRE, Notes annexes, analytique ; clôture périodique (mensuelle) et annuelle définitive avec report à nouveau. **Au web : tout. Au poste : consultation hors ligne et DEMANDES** (le poste n'écrit jamais `fiscal_years`, `periodic_closures` ni une écriture d'à-nouveau ; il envoie une demande rejouée par le serveur, qui numérote et décide).

## 4. Journal Comptable

Colonnes : **JAL** (code journal de logialvia : VT ventes, AC achats, CA caisse, OD — Opérations Diverses ; `comptabilite_tables.dart`) · DATE · N° PIÈCE · COMPTE · LIBELLÉ · DÉBIT · CRÉDIT ; ligne de TOTAUX : TOTAL DÉBIT (PÉRIODE), TOTAL CRÉDIT (PÉRIODE), ÉQUILIBRE (badge vert si égaux). Recherche « Libellé, compte, n° de pièce… » ; filtre exercice/période ; pagination 25 lignes (« 27 lignes dans l'exercice 2026 — page 1 sur 2 », Précédent / Suivant). Infobulle d'une écriture automatique : « Écriture générée automatiquement par V-2026-001 » (non modifiable ici ; correction = événement source ou contre-passation). Le tableau représente une écriture RÉELLE à N lignes (écart délibéré avec le prototype qui ne le savait pas).
**Bouton « Nouvelle Écriture »** (OD — Opérations Diverses) → modale : date * (exercice OUVERT, mois non clôturé), libellé *, lignes (compte *, débit OU crédit, jamais les deux), contrôle d'équilibre AVANT écriture : « Pièce déséquilibrée : débit X ≠ crédit Y. » ; « Les montants ne peuvent être négatifs. » ; « Le compte est obligatoire. » ; « Le libellé est obligatoire. » ; « Une écriture porte un débit OU un crédit, jamais les deux. » ; « Saisissez un montant au débit ou au crédit. » ; débit ≠ crédit pour une écriture à deux lignes ; numéro `OD-AAAA-NNNN` attribué par le SERVEUR (année de l'écriture ; RM-CPT-08) ; une écriture à plus de deux lignes, verrouillée ou d'à-nouveau ne se retouche pas ; **archivage = contre-passation exacte** (jamais suppression ni corbeille : TRANCHÉ DV-05, Q-CPT-3 fermée ; `supprimerPiece` de logialvia est retirée et le type « écriture » sort de la corbeille, `29_` onglet 6). **Contre-passation** : bouton « Contre-passer » sur une écriture non verrouillée d'un exercice ouvert (mois non clôturé) ; crée l'écriture inverse exacte (débits et crédits échangés, même axe analytique, libellé « Contre-passation de <n° pièce> », date du jour, numéro serveur) ; l'originale reste visible, marquée « Contre-passée » ; on saisit ensuite une nouvelle écriture correcte (`15_` RM-CPT-09). Refus : exercice clos, mois clôturé, déjà contre-passée. Une écriture ne se restaure jamais. Source unique : `AccountingEntryService::record()` / `recordManual()`.
**Écritures automatiques** (RM-CPT-01) par événement : vente (D 531 ou 512 ou 411 / C 701 ou 707 [+ C 443 si TVA]), règlement de créance (D 531/512 / C 411), avance reçue (419), achat (D 601/602 [+ D 445] / C 401 ou trésorerie), dépense (D charge / C trésorerie), soins vétérinaires (622), annulation (contre-passation avec le MÊME axe analytique), avoir (inverse), paie (si module), immobilisation, dotation. Numéros de comptes repris tels quels des sources, à valider par l'expert-comptable (Q-CPT-1).

## 5. Grand Livre, Balance, Plan comptable

**Grand Livre** : sélecteur de compte (« COMPTE : », recherche numéro/libellé ; s'ouvre sur 531), KPI (Solde d'Ouverture, Total Débit Période, Total Crédit Période, Solde Final), tableau Date · N° Pièce/Origine · Libellé · Débit · Crédit · **Solde Progressif** (RM-CPT-02 ; solde d'ouverture reporté même filtré par période), « Imprimer PDF ».
**Balance Générale** : sélecteur de période (« Mois en cours — Août 2026 », trimestre, exercice) ; colonnes N° COMPTE · LIBELLÉ · SOLDE OUVERTURE (D/C) · MOUVEMENTS PÉRIODE (D/C) · SOLDE FINAL (D/C) ; TOTAUX ; **« ÉCART (DOIT ÊTRE 0) »** en rouge si ≠ 0 (RM-CPT-03) ; un compte sans écriture n'apparaît jamais comme solde 0.
**Plan comptable** : colonnes N° COMPTE · INTITULÉ · CLASSE (« 2 - Immobilisations » : libellé de classe unique pour écran, sélecteur et PDF) · SENS · ACTIONS (Modifier, Archiver) ; bouton « Nouveau Compte ». Règles : le numéro est IMMUABLE à la modification ; classe cohérente avec le premier chiffre ; archivage refusé si une écriture cite le compte ; jamais de suppression ; plan SYSCOHADA révisé fourni par le client (≈ 1 332 lignes chez LogiAgriERP, `agrierp_laravel/database/data/plan-comptable-syscohada-revise.csv`) importé par INSERTION SEULE avec empreinte SHA-256 vérifiée par test (guide bloc 9 ; **Q-CPT-7** : le client a-t-il son CSV officiel ? les comptes semés par logialvia sont-ils conservés ?).

## 6. États Financiers (4 onglets) et Bilan de l'Entreprise

Sélecteur d'exercice commun, bouton « Exporter PDF (Onglet Actif) ». Colonnes N et N-1 (N-1 = l'exercice précédent À SA CLÔTURE, pas « à date égale »).
**« Bilan »** (ACTIF / PASSIF SYSCOHADA) : Actif immobilisé (20 charges immobilisées ; 21 incorporelles ; 22-24 corporelles ; 26-27 financières) ; Actif circulant (stocks classe 3 ; créances classe 4 soldes débiteurs) ; Trésorerie-Actif (classe 5 débiteurs) ; Passif : Capital (10), Réserves/RAN/Résultat (11-13), Dettes financières (16-19), Dettes circulantes (classe 4 créditeurs), Trésorerie-Passif ; TOTAL GÉNÉRAL ACTIF = TOTAL GÉNÉRAL PASSIF (badge vert/rouge permanent).
**« Compte de Résultat »** en cascade : Ventes (70) − Achats consommés (60) = MARGE COMMERCIALE ; + production − consommations des tiers = VALEUR AJOUTÉE ; − personnel (66) − impôts et taxes (64) = EXCÉDENT BRUT D'EXPLOITATION ; − dotations (68) = RÉSULTAT D'EXPLOITATION ; ± résultat financier (77 − 67) = RÉSULTAT DES ACTIVITÉS ORDINAIRES ; ± HAO ; − participation − IS = RÉSULTAT NET DE L'EXERCICE (= compte 13 du bilan : contrôle croisé automatique, alerte sinon).
**« Flux de Trésorerie »** (TAFIRE simplifié) : FLUX NET DE TRÉSORERIE D'EXPLOITATION (résultat net + dotations − variation du BFR) ; D'INVESTISSEMENT (− acquisitions + cessions) ; DE FINANCEMENT (± emprunts, apports) ; VARIATION DE TRÉSORERIE DE LA PÉRIODE ; trésorerie d'ouverture + variation = trésorerie de clôture (= Trésorerie-Actif du bilan : contrôle TAFIRE ↔ Bilan réellement exécuté).
**« Notes Annexes »** : Note 1 Méthodes comptables (texte), Note 2 Immobilisations (calculée), Note 3 Stocks (calculée), Note 4 Créances et dettes (calculée, ancienneté), Note 5 Engagements hors bilan (texte, vide par défaut) ; colonnes COMPTE · INTITULÉ · NATURE · MONTANT ; un formulaire par note, lié à l'exercice (`NOTES_ANNEXES`) ; 3 calculées, 2 rédigées.
**Bilan de l'Entreprise** (écran distinct de l'onglet Bilan : pour la Gérante, « qu'est-ce que je possède, qu'est-ce que je dois ? ») : 7 postes réellement mouvementés : ACTIF Stocks (31/32), Clients 411, Banques — Mobile Money 512, Caisse 531 ; PASSIF Capital Initial 101, Résultat de l'Exercice (via `CalculerResultatNet`, jamais un compte 13 lu), Fournisseurs 401 ; **le capital est LU au 101, jamais déduit comme variable d'ajustement** ; écart affiché sur sa ligne en rouge ; bandeau à 3 états (vide, équilibré, en écart) nommant la cause et l'action (saisir l'apport au 101 depuis le Journal).
**Après clôture** : états justes, jamais « historique + à-nouveau » ; l'écriture de solde (étape 2) est écartée du Bilan et du Compte de résultat (le résultat reste sur « Résultat de l'exercice »), mêmes totaux (R1 du PRD d'exercices).

## 7. Comptabilité analytique

Colonnes : CENTRE DE COÛT / PROFIT · REVENUS · COÛTS DIRECTS · MARGE · TAUX DE MARGE ; TOTAL. Axe porté par la LIGNE d'écriture (`axeAnalytique`, v19) : vente → axe d'après la filière du produit (une ligne 701 par filière) ; annulation → même axe ; dépense → sélecteur « Centre analytique (facultatif) » ; **axe prime sur l'heuristique du numéro de compte** (601/622 avicole, 602 commerce annexe), une ligne comptée par l'axe n'est jamais recomptée ; charges de structure (613, 616, 624, 628) jamais réparties au prorata ; « Avicole — filière non précisée » = un centre à part ; invariant : Σ marges + produits non affectés − charges non affectées = Résultat net ; écritures antérieures non réimputées. **À DÉFINIR** (Q-CPT-5) : axes pisciculture/lapins/pondeuses (la vente de « Poisson-chat vif (kg) » a-t-elle son axe ?) et clé de répartition éventuelle des charges communes.

## 8. Clôture d'exercice (`/comptabilite/cloture`)

**Deux onglets/volets** : « Clôture périodique » (mensuelle : 12 boutons « Clôturer janvier » … « Clôturer décembre » ; liste des mois clos avec « Déclôturer » visible pour `admin` seul, journalisé ; vérifie la balance ; pas de report à nouveau ; RM-CPT-05) et « Clôture annuelle ». **KPI/volet** : EXERCICE · BALANCE (équilibrée ou non) · COMPTES DE GESTION À SOLDER · RÉSULTAT PROVISOIRE. Bouton « Clôturer l'Exercice 2026 » actif seulement sans anomalie bloquante ; modale de confirmation renforcée : « Cette action verrouille définitivement toutes les écritures de cet exercice… Un nouvel exercice sera créé avec les soldes de report à nouveau. » + saisie « CLOTURER ».
**Règles** (RM-CPT-06, J1) : une transaction ; si une étape échoue rien ne s'exécute ; verrouillage définitif (aucun déblocage annuel). **Gardes LogiAgriERP proposées** : échéance passée, étapes 1 et 2, N−1 clos, à-nouveau équilibré, classe 8 non soldée bloquante, ouverture de N+1 le 1er janvier (tâche + filet à la première saisie, et par bouton dès le 1er décembre ; deux exercices ouverts au plus). **Étapes poste** : jamais directes — demandes `fiscal_closure_requests` (`cloturer_periode`, `decloturer_periode`, `confirmer_etape1`, `solder_comptes_gestion`, `cloturer_exercice`, `ouvrir_exercice`…) rejouées dans l'ordre d'INSERTION. **Exercice clos verrouillé** : saisies de stock, fiches d'élevage, paie, déplacement d'écriture, date d'une dépense comptabilisée REFUSÉS (messages en JJ/MM/AAAA) — constat LogiAgriERP C1/C2 : sans ouverture automatique de N+1 la caisse se bloque le 1er janvier : **construire l'ouverture dès W8**. Archivage : sauvegardes à 30 jours chez LogiAgriERP, pas d'archive figée à la clôture (**Q-CPT-8** : archive PDF/xlsx figée de l'exercice à la clôture ?).

## 9. Immobilisations et TVA (PROPOSÉ — absents de logialvia)

**Immobilisations** : registre, acquisition (capitalisation : contrepartie vide / `credit` / compte de trésorerie), modification (valeur figée si comptabilisée), SORTIE (cession/réforme, jamais suppression), dotation datée idempotente (écart recalculé contre le grand livre) ; `isCapitalized` posé par le point de passage, pas par l'écran ; méthode, durées, prorata, mois entiers ou à virgule : **Q-CPT-4**. **TVA** : drapeau « assujetti » (RM-TVA-01) ; Déclaration de TVA mensuelle (mois de l'exercice affiché seulement) ; seules les factures transmises/normalisées y figurent (à confirmer : Q-TVA-1) ; taux 0 % et 18 % ; groupes A/B. **Paie** : écriture au serveur (`27_`).

## 11. Critères d'acceptation

- [ ] Vente Espèces 8 000 sans TVA : D 531 8 000 / C 701 8 000 ; pièce 8 000 / 7 999 refusée.
- [ ] Cas RM-CPT-03 : Σ soldes finaux D = Σ C = 18 000, écart 0 ; résultat net 3 000 identique au Compte de résultat, au compte 13 et au point de départ du TAFIRE.
- [ ] Clôture : RAN = 531 D 13 000 ; 101 C 10 000 ; 131 C 3 000 ; l'exercice clos refuse toute modification ; N+1 ne double pas les soldes (état juste).
- [ ] Clôture refusée le 15/11/2026 (échéance non passée).
- [ ] Journal d'un exercice clos : boutons remplacés par un cadenas ; écritures manuelles dans un mois clos refusées sauf déblocage admin journalisé.
- [ ] Plan : archivage d'un compte cité refusé ; numéro immuable ; empreinte du CSV vérifiée.
- [ ] Bilan de l'Entreprise : sans apport au 101, écart rouge sur sa ligne (le bandeau n'est jamais « équilibré » par construction).
- [ ] Un animalier/caissier en URL directe `/comptabilite/*` : refus ; le comptable y accède (DV-07).
- [ ] Écriture erronée D 531 8 000 / C 701 8 000 : contre-passation D 701 8 000 / C 531 8 000 puis nouvelle écriture 7 000 ; aucune route de suppression ni de restauration d'écriture ; une seconde contre-passation est refusée (DV-05).
